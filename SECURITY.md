# Security Policy

## Supported Versions

This historical repository has no supported versions. Use [`sas-ci360-solutions`](https://github.com/mnelson3/sas-ci360-solutions) for the maintained orchestration implementation.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting feature when available, or email `support@nelsongrey.com` with the subject prefix `[Security]`.
